# tiny-chess-01

[![make.fun](https://img.shields.io/badge/make.fun-tiny--chess--01-blue)](https://make.fun/bounty/tiny-chess-01)

A chess engine in 4 KB of Python, built for the [tiny-chess-01 bounty](https://make.fun/bounty/tiny-chess-01): alpha-beta search with quiescence, transposition table and piece-square evaluation. `main.py` is the whole engine (4,062 bytes).
